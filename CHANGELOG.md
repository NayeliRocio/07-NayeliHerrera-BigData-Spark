# Changelog

## [2.0.0] - EN PREPARACIÓN (S07)

### Cambiado
- Se sustituyó la arquitectura anterior Python/PySpark por Java 17 + Maven multi-módulo.
- Se adoptó la organización de referencia: contracts, spark-worker, backend-api y frontend.

### Agregado
- Modelos Java compartidos para el caso IPD.
- Worker Apache Spark Java con CSV de demostración, limpieza, deduplicación y agregación.
- Pruebas unitarias de reglas de calidad.
- API REST de ejemplo y frontend simple para demostrar la arquitectura.
- Documentación actualizada del alcance y ejecución.

### Nota
La versión 2.0.0 está preparada en una rama de trabajo, no publicada como release
hasta integrarla y validarla en el repositorio institucional.

## [1.0.0] - 2026-09-21 (histórica)

- Primera estructura académica elaborada en Python/PySpark.
- Git Flow inicial y documentación. El profesor indicó que debía usarse Java.
